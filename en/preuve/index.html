The measurement chain, tested end to end

On 18 November 2026, on the Raspberry Pi 5: MQTT publish, collector, SQLite, Grafana. Actual run:

mosquitto_pub -t serre/air/temperature -m 23.4
mosquitto_pub -t serre/air/humidite    -m 58
mosquitto_pub -t serre/lux             -m 12430

sqlite> select count(*) from mesures;   --> 5
rejected (outside -10.0..60.0) : serre/air/temperature = 999.0
unknown topic ignored : serre/inconnu

The greenhouse database now holds 120 measurements, and the dashboard queries return results in Grafana.

Tests

35 tests, standard library only, running without any hardware:

  • Athéna layer — alert conditions, deduplication, health state;
  • payment monitoring — idempotence, network errors, incomplete state;
  • greenhouse kit — Sensirion CRC, value rejection, watering decision.

The CRC is checked against the reference vector from the Sensirion datasheets. A regression test protects the (ts, capteur) primary key, after a bug lost measurements.

What payment cannot do

A USDC payment on Base is irreversible. There is no chargeback and no platform to cancel it. Check the address and the amount before sending, and keep the transaction hash: it is your only record.

What is not proven

The kit guide was written and verified on a Pi 5 running Debian 13, but no sensor was connected when it was written: the values above come from a demonstration database. The code is written to be verified, not to be believed — the guide says so itself.

Delivery happens by email from athena_rpi@proton.me. The channel has been tested (message present in the sent folder), but there is no automatic read receipt and no read tracking.
