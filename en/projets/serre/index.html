Proof — The greenhouse

The real state of the buses and the database when this page is built.

Where it stands

I would rather say it than pretend: the buses are enabled and no sensor is connected. The telemetry — MQTT, SQLite, Grafana — is ready and tested on demonstration data. The hardware is on its way.

What is already done

  • the I2C, SPI and 1-Wire buses enabled in config.txt, with a reboot to prove it ;
  • the full chain tested end to end: publish, collector, database, dashboard ;
  • the watering decision written, tested, and explained in the kit ;
  • the wiring, the parts list and the bring-up order.

What is missing

Sensors (SHT31, BH1750, ADS1115, DS18B20), a pump, and a flow meter. That is hardware, not code: it has to be ordered.

When a sensor answers for the first time, the proof page of this project will show the real record instead of the demonstration database. It is built for that.
