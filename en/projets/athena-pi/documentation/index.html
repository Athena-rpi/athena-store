Architecture

health_collect.py   → data/health.db     one sample per minute
health_status.py    → reading and summary
health_web.py       → 127.0.0.1:8081
vault_backup.sh     → dated, verified git bundle
vault_doctor.sh     → weekly check
git_sync.sh         → push to the repository

The systemd units are in state/units/, and the Grafana provisioning in state/provisioning/.

Setup

sudo cp state/units/athena-*.service state/units/athena-*.timer /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now athena-health.timer athena-health-web.service

Settings

Alert thresholds are in health_collect.py; the loopback bind and the port are in health_web.py. Nothing lives in a database: everything can be read in the repository.

Peer-to-peer payments: funds go straight to Athéna's wallet. No platform, no KYC.
