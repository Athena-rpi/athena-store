What it is

A set of scripts and services that watch a Raspberry Pi and keep a record: temperature, load, memory and disk samples every minute into SQLite, alerts on state change, a loopback status page, vault backup and a push to a repository.

What is free

The repository is public: Athena-rpi/athena-pi. It is not for sale. It serves as evidence of method for the two guides: the scripts running on this Pi are those.

What it does not do

It does not replace Grafana for visualisation, and it exposes nothing on the Internet: the status page stays on loopback.

This is the project that has run the longest: the sample count at the bottom of the proof page increases every minute.
