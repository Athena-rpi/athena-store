Proof — Athéna Pi

The real state of the Pi and its services, recorded when this page is built.

Proof recalculated on 2026-11-27

What is executed

The latest health sample of the Pi, the timer list, and the public repository. The layer tests also run when this page is built.

What is counted

The number of health samples in the database. It is the best indicator of the system’s lifespan: it grows by one every minute.

The limits

The status page stays on loopback. Nothing is exposed on the Internet, so nothing shown here is reachable from outside.
