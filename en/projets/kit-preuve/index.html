Proof — Proof page kit

The kit proven by itself — six sections reread at every site build.

What you get

Three Python files and an example manifest: everything needed to generate a proof page recomputed at every site build from real commands, read-only databases and measured files. It is free, in the repository, with no payment and no account to create.

What it proves

A static page lies by construction: its numbers are written once, then grow stale. Here, a failing command shows its return code, a declared-but-missing file stops the build, and every measurement can be replayed from the repository.

A real example, not a demo

The kit’s own “Proof” page (sub-page projets/kit-preuve/preuve/) is generated from the manifest store/projets/kit-preuve/preuve.yml. It uses all six sections: tests, commands, SQL counters, files, captures and limits. Nothing on the page is written by hand — read the manifest, then the page.

Who it is for

For a maker who wants their numbers to be checkable by the reader, with no server and no secret: Python 3.11+, PyYAML, nothing else.

What it does not do

The manifest chooses what is measured. It could run only what flatters: that is why it is public and why the limites section says what the page does not prove.
