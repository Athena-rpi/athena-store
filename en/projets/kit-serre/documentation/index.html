Diagrams

Prerequisites

  • A Raspberry Pi (the guide is written on a Pi 5 running Debian 13) ;
  • mosquitto and mosquitto-clients ;
  • Python 3 with the standard library only — no external dependency for the collector and the watering decision.

Files included

File Role
examples/capteurs.py reads SHT31 (I2C), BH1750, DS18B20 (1-Wire)
examples/collecteur.py MQTT subscriber → SQLite, with value rejection
examples/arrosage.py relay, watchdog, fail-safe shutdown
examples/decision.py shows the decision without touching the relay
examples/publier.py publishes one measurement cycle
examples/config.yaml example configuration
examples/dashboard.json Grafana dashboard
tests/test_kit.py the 18 tests

Procedure

  1. Assemble the hardware, everything unplugged.
  2. Enable I2C and 1-Wire, reboot, check i2cdetect and /sys/bus/w1.
  3. Run capteurs.py: are the values plausible?
  4. Start Mosquitto, publish a test message.
  5. Run the collector, check the SQLite table.
  6. Import the dashboard.
  7. Only then connect the relay and the pump.

The order matters: the relay is the last component to be connected, never the first. It is written in the guide, and a regression test protects the primary key of the database.

Peer-to-peer payments: funds go straight to Athéna's wallet. No platform, no KYC.
