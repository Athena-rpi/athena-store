What is actually executed for this project, recalculated when this page is built.

Proof recalculated on 2026-11-19

What is tested

The kit is tested on logic, not on hardware: the SHT31 CRC, out-of-range rejection, the primary key of the database, and the watering decision conditions. These tests run on any machine.

What is executed

The commands below are executed when this page is built. They are not copied by hand: if the code changes, the proof changes or the build fails.

The limits

They are at the bottom of the page, under “What is not proven”. That is deliberately the last block, not a footnote in small print.
