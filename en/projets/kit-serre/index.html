What you get

A 7-page PDF guide and 11 files: the Python collector code, the Grafana dashboard, the parts list, the systemd unit, and wiring examples. The guide starts from zero — you do not need a sensor already wired to follow it.

What it does

  • measures air (SHT31: temperature, humidity), soil (DS18B20, humidity) and light (BH1750) ;
  • publishes to MQTT, then writes to SQLite after rejecting out-of-range values — a failing sensor must not trigger a fake watering ;
  • decides watering on an explicit rule, and cuts the pump on an empty tank, an out-of-window hour, or a silent collector ;
  • shows a Grafana dashboard built on the data.

What it does not do

It does not run an existing installation turnkey: it gives you the method, the code and the settings, and you do the wiring. The relay is deliberately the last component in the guide, not the first.

Why the watering rule is the argument

The pump only starts when four conditions all hold: soil below threshold, tank full, inside the time window, and a delay elapsed since the last cycle. A missing sensor or an empty tank blocks watering. It is written down, tested, and it is the kind of detail that keeps a greenhouse from being flooded.

The rule, in real conditions

Dry soil, full tank, noon — the pump starts

commande

python3 decision.py --sol 20 --cuve 1 --depuis 900 --heure 12

sortie

sol 20.0 % (seuil 25 %), cuve pleine, dernier cycle il y a 900 s
heure locale 12h00 (fenêtre 6h–21h)
conditions :
  sol < 25 %          : oui
  cuve pleine         : oui
  dans la fenêtre horaire : oui
  délai >= 600 s      : oui
décision : POMPE ON

Wet soil — the pump stays off
