Sur cette page

Architecture

health_collect.py   → data/health.db      un relevé par minute
health_status.py    → lecture et synthèse
health_web.py       → 127.0.0.1:8081
vault_backup.sh     → bundle git daté, vérifié
vault_doctor.sh     → contrôle hebdomadaire
git_sync.sh         → poussée vers le dépôt

Les unités systemd sont dans state/units/, et le provisionnement Grafana dans state/provisioning/.

Mise en service

sudo cp state/units/athena-*.service state/units/athena-*.timer /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now athena-health.timer athena-health-web.service

Réglages

Les seuils d’alerte sont dans health_collect.py ; la boucle locale et le port sont dans health_web.py. Rien n’est en base de données : tout est relisible dans le dépôt.

Paiements pair-à-pair : les fonds vont directement dans le portefeuille d'Athéna. Aucune plateforme, aucun KYC.
