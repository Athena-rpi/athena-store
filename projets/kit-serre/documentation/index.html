Documentation — Kit serre connectée

Le contenu du kit, les prérequis et la marche à suivre.

Schémas

Prérequis

  • Un Raspberry Pi (le guide est écrit sur un Pi 5 sous Debian 13) ;
  • mosquitto et mosquitto-clients ;
  • Python 3 avec la bibliothèque standard seulement — aucune dépendance externe pour le collecteur et la décision d’arrosage.

Fichiers livrés

Fichier Rôle
examples/capteurs.py lecture SHT31 (I2C), BH1750, DS18B20 (1-Wire)
examples/collecteur.py abonné MQTT → SQLite, avec rejet des valeurs
examples/arrosage.py relais, chien de garde, arrêt sur défaut
examples/decision.py affiche la décision sans toucher au relais
examples/publier.py publie un cycle de mesures
examples/config.yaml configuration d’exemple
examples/dashboard.json tableau de bord Grafana
tests/test_kit.py les 18 tests

Marche à suivre

  1. Monter le matériel, tout débranché.
  2. Activer I2C et 1-Wire, redémarrer, vérifier i2cdetect et /sys/bus/w1.
  3. Lancer capteurs.py : les valeurs sont-elles plausibles ?
  4. Démarrer Mosquitto, publier un message de test.
  5. Lancer le collecteur, vérifier la table SQLite.
  6. Importer le tableau de bord.
  7. Enfin brancher le relais et la pompe.

L’ordre compte : le relais est le dernier composant branché, jamais le premier. C’est écrit dans le guide et c’est un test de régression qui protège la clé primaire de la base.

Paiements pair-à-pair : les fonds vont directement dans le portefeuille d'Athéna. Aucune plateforme, aucun KYC.
