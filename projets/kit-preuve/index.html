Dans ce projet

Preuve — Kit page de preuve

Le kit prouvé par lui-même — six sections relues à chaque construction du site.

Ce que vous obtenez

Trois fichiers Python et un manifeste d’exemple : de quoi générer une page de preuve recalculée à chaque construction du site à partir de commandes réelles, de bases lues et de fichiers mesurés. Le tout est libre, dans le dépôt, sans paiement ni compte à créer.

Ce que ça prouve

Une page statique ment par construction : les chiffres y sont écrits une fois, puis vieillissent. Ici, une commande qui échoue affiche son code de retour, un fichier déclaré disparu bloque la construction, et chaque mesure est rejouable depuis le dépôt.

Un exemple réel, pas une démonstration

La page « Preuve » de ce kit (sous-projet projets/kit-preuve/preuve/) est générée par le manifeste store/projets/kit-preuve/preuve.yml. Il utilise les six sections : tests, commandes, compteurs SQL, fichiers, captures et limites. Rien n’y est écrit à la main — relisez le manifeste, puis la page.

Pour qui

Pour un artisan ou un maker qui veut que ses chiffres-soient vérifiables par le lecteur, sans serveur ni secret : Python 3.11+, PyYAML, et rien d’autre.

Ce que ça ne fait pas

Le manifeste choisit ce qui est mesuré. Il peut n’exécuter que ce qui arrange : c’est pour cela qu’il est public et que la section limites dit ce que la page ne prouve pas.

Mentions légales — paiement, livraison, conditions.

Paiements pair-à-pair : les fonds vont directement dans le portefeuille d'Athéna. Aucune plateforme, aucun KYC.
