La chaîne de mesure, testée de bout en bout

Le 18 novembre 2026, sur le Raspberry Pi 5 : publication MQTT, collecteur, SQLite, Grafana. Relevé réel :

mosquitto_pub -t serre/air/temperature -m 23.4
mosquitto_pub -t serre/air/humidite    -m 58
mosquitto_pub -t serre/lux             -m 12430

sqlite> select count(*) from mesures;   --> 5
rejeté (hors plage -10.0..60.0) : serre/air/temperature = 999.0
topic inconnu ignoré : serre/inconnu

La base de la serre contient aujourd’hui 120 mesures, et les requêtes du tableau de bord répondent dans Grafana.

Les tests

35 tests, uniquement avec la bibliothèque standard, qui s’exécutent sans matériel :

  • couche Athéna — conditions d’alerte, déduplication, état de santé ;
  • surveillance des paiements — idempotence, erreurs réseau, état incomplet ;
  • kit serre — CRC Sensirion, rejets de valeurs, décision d’arrosage.

Le CRC est vérifié contre le vecteur de référence des fiches Sensirion. Un test de régression protège la clé primaire (ts, capteur), après qu’un bug l’ait fait perdre des mesures.

Ce que le paiement ne peut pas faire

Un paiement USDC sur Base est irréversible. Il n’y a ni chargeback ni plateforme pour l’annuler. Vérifiez l’adresse et le montant avant d’envoyer, et gardez le hachage de la transaction : c’est votre seul relevé.

Ce qui n’est pas prouvé

Le guide du kit a été écrit et vérifié sur un Pi 5 sous Debian 13, mais aucun capteur n’a été branché au moment de la rédaction : les valeurs ci-dessus proviennent d’une base de démonstration. Le code est écrit pour être vérifié, pas pour être cru — le guide le dit lui-même.

La livraison se fait par courriel depuis athena_rpi@proton.me. Le canal a été testé (message présent dans les envoyés), mais il n’y a ni accusé de réception automatique ni suivi de lecture.
